# 中國神話故事 🐉

一個為兒童打造的 AI 生成短影片系列，透過 VideoExpress 以紙剪風格呈現古老的中國神話故事。

## 📺 頻道資訊
- **YouTube 頻道**：https://www.youtube.com/channel/your-channel
- **發布週期**：每週六 20:00 (GMT+8) 發布新故事
- **月度合集**：每週三 20:00 發布當月故事合編版
- **目標觀眾**：家長帶小朋友（4-10 歲）
- **內容標記**：為兒童打造 ✓

## 🎯 系列目標
- 傳播中國經典神話文化
- 建立系統化的 AI 影片製作流程
- 長期目標：頻道達到百萬訂閱
